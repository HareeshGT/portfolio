KubeDock

            

              A desktop control center for AWS EC2, Kubernetes, SSH, SFTP, FTP
              and remote files. Manage infrastructure from one application
              instead of juggling terminals, SSH clients and dashboards.
            

            
    
              
  • Integrated SSH terminal and a Finder-style remote file manager with sudo filesystem access
    • 
              
  • Kubernetes dashboard: pods, deployments, services, events, live logs, exec and port forwarding
    • 
              
  • Direct streaming of remote video and audio over SSH/SFTP or FTP, with no download
    • 
              
  • Embedded FastAPI web app for monitoring and operating clusters from a phone
    • 
              
  • AI-assisted troubleshooting, PIN app lock (PBKDF2-SHA256) and a multi-theme UI
    •
